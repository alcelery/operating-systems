# README: Создание снимков виртуальной машины (VirtualBox)

## Описание
Домашнее задание по дисциплине "Операционные системы и среды". Цель работы — освоить механизм снимков (snapshots) виртуальной машины в Oracle VirtualBox: сохранять состояние системы, имитировать "поломку" и откатываться к рабочему состоянию.

## Что понадобится
- Oracle VirtualBox (официальный сайт)
- Образ ВМ — файл `Learning Debian.ova` (ссылка в презентации, ССЛ.ПУСА НА ОБРАЗ РМ)
- Word/PDF для оформления отчёта

## Ход работы

| № | Шаг |
|---|-----|
| 1 | Скачать и установить VirtualBox |
| 2 | Скачать `Learning Debian.ova` и импортировать его в VirtualBox |
| 3 | Полностью завершить сеанс ВМ, перейти во вкладку "Снимки", нажать "Сделать" |
| 4 | Задать имя снимка (например, `deb1`) и описание, сохранить |
| 5 | Запустить ВМ, войти как root |
| 6 | Выполнить "патч Бармина" — команду удаления системы: `rm -rf --no-preserve-root /` |
| 7 | Принудительно выключить ВМ, запустить снова (ожидается `kernel panic`) |
| 8 | Откатиться: выбрать снимок, нажать "Восстановить" |
| 9 | Запустить ВМ — система работает как до "поломки" |

## Замечания по выполнению
- "Патч Бармина" — это имитация поломки (удаление всей системы), а не реальный патч.
- В презентации ожидается `kernel panic`, но на практике может появиться сообщение `run-init: can't execute '/sbin/init'` и приглашение `(initramfs)` — это нормальный результат разрушения системы.
- Иногда ВМ после патча может загрузиться без ошибок — зависит от момента принудительного выключения.
- Восстановление снимка возвращает систему в рабочее состояние — это и есть суть механизма.

## Требования к отчёту
