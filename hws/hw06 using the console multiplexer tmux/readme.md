# README: Приложения

## Описание
Домашнее задание по дисциплине "Операционные системы и среды". Цель работы — освоить консольный мультиплексор tmux: создание и переименование окон, разделение рабочей области, переключение между областями и выполнение команд в разных панелях. Работа выполняется в гостевой ОС Debian (VirtualBox), в терминале.

## Что понадобится
- Oracle VirtualBox с импортированным образом ВМ.
- Терминал ВМ, вход как root.
- Установленный `vim` и `python3` (обычно уже есть в Debian).
- Word/PDF для оформления отчёта.

## Сокращения клавиш
- Префикс tmux — `Ctrl + B`. Далее идёт клавиша действия (нажимаются последовательно, не одновременно).

## Ход работы

| № | Задание | Команда / действие |
|---|---------|--------------------|
| 1 | Установить tmux | `apt install tmux` |
| 2 | Запустить мультиплексор, сравнить с обычным терминалом | `tmux` |
| 3 | Создать новое окно | `Ctrl + B`, затем `C` |
| 4 | Переименовать окно в `Text` и запустить vim | `Ctrl + B`, затем `,` (запятая), ввести имя; `vim` |
| 5 | Написать в vim скрипт на Python для записи секунд в `test.txt` | см. листинг ниже |
| 6 | Запустить скрипт | `python3 timer.py`, прервать `Ctrl + C` |
| 7 | Перейти в предыдущее окно | `Ctrl + B`, затем `0` |
| 8 | Следить за размером файла | `watch -n 1 'ls -l test.txt'` |
| 9 | Остановить watch и прервать Python | `Ctrl + C` в обоих окнах; переход в первое окно: `Ctrl + B`, затем `1` |
| 10 | Закрыть второе окно | `exit` |
| 11 | Разделить окно по горизонтали, установить fastfetch справа | `Ctrl + B`, затем `%`; в правой области `apt install fastfetch` |
| 12 | Перейти в левую область, после установки запустить fastfetch | `Ctrl + B` + стрелка; `fastfetch` |
| 13 | Закрыть правую область | `exit` |
| 14 | Разделить окно по вертикали (эксперимент) | `Ctrl + B`, затем `"` (двойные кавычки) |
| 15 | Закрыть все области | `exit` (несколько раз) |

## Листинг скрипта (timer.py)

```
import time

start = time.time()
f = open("test.txt", "w")

while True:
    f.write(str(time.time() - start) + "\n")
    f.flush()
    time.sleep(1)
```

## Замечания по выполнению

- tmux-команды набираются последовательно: сначала префикс Ctrl + B, отпустить, затем клавиша действия (c, ,, 0, 1, %, ").
- В vim для выхода без сохранения: Esc, затем :q!; для сохранения: Esc, :wq.
- watch -n 1 'ls -l test.txt' показывает обновление размера файла раз в секунду. Через cat файл будет перерисовываться целиком, а не показывать рост — поэтому удобнее ls -l.
- f.flush() в скрипте нужен, чтобы данные сразу попадали в файл, а не копились в буфере.
- Деление окна: % — по горизонтали (панели слева/справа), " — по вертикали (панели сверху/снизу). Деления можно комбинировать.
- Переход между панелями: Ctrl + B, затем клавиши-стрелки.
- В отчёте на шаге 11 видна ошибка E: install: missing destination file operand after 'fastfetch' — это следствие опечатки в команде (apt install fastfetch набрано не полностью или с лишним пробелом). Правильная команда: apt install fastfetch.
- fastfetch — утилита вывода информации о системе (аналог neofetch).

## Требования к отчёту
- Оформляется в Word/PDF.
- Каждый шаг фиксируется: команда/действие + скриншот.
- В конце — вывод: какие знания извлечены, какие приёмы работы с tmux освоены.
