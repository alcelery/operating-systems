# Автоматизация сборки Unix Makefiles

## Описание
Домашнее задание по дисциплине "Операционные системы и среды". Цель работы — освоить утилиту `make` и файл `Makefile` для автоматизации сборки программы на ассемблере (GASM): компиляция (`as`), компоновка (`ld`) и очистка объектных файлов одной командой. Работа выполняется в гостевой ОС Debian (VirtualBox), в терминале.

## Что понадобится
- Oracle VirtualBox с импортированным образом ВМ.
- Терминал ВМ, вход как root (или `sudo`).
- Пакет `binutils` (компилятор `as` и компоновщик `ld`).
- Word/PDF для оформления отчёта.

## Подготовка
Установить пакет binutils, если не установлен:
```bash
apt install binutils
```

Создать файл `main.s` с простым исходным кодом на GASM:

```asm
.global _start
.section .text
_start:
    movq $60, %rax
    movq $67, %rdi
    syscall
```

Это простейшая программа, завершающаяся с кодом возврата 67 (syscall 60 = exit).

## Задание 1. Создать Makefile

```makefile
main.o: main.s
	as -o main.o main.s

main: main.o
	ld -o main main.o

clean:
	rm -f *.o

build: main clean

.PHONY: clean build
```

Важно: в строках-командах используется **табуляция**, а не пробелы.

## Задание 2. Собрать программу одной командой

```bash
make build
```

Последовательность, которую выполнит make:
1. `main` — проверит зависимость `main.o`;
2. `main.o` — проверит изменение `main.s`, при необходимости вызовет `as -o main.o main.s`;
3. `ld -o main main.o` — скомпонует исполняемый файл;
4. `clean` — удалит объектные файлы `*.o`.

## Замечания по выполнению
- Makefile — командный файл, описывающий цели (targets) и зависимости между ними.
- Синтаксис правила: `цель: [зависимости]`, на следующей строке — команда (с табуляцией).
- Цель может быть файлом (`main`, `main.o`) или абстрактной (`clean`, `build`).
- `.PHONY` помечает абстрактные цели — для них make не проверяет наличие файла с таким именем, а выполняет команды всегда.
- Благодаря зависимостям make не перекомпилирует то, что не изменилось — это ускоряет сборку.
- В отчёте использовался код exit с `%rdi = 67`; после сборки можно проверить код возврата: `./main; echo $?` (должно вывести 67).
- Если `make` ругается `missing separator`, значит в командах стоят пробелы вместо табуляции.

## Требования к отчёту
- Оформляется в Word/PDF.
- Каждый шаг фиксируется: код + скриншот выполнения.
- В конце — вывод: какие знания извлечены, какие приёмы автоматизации сборки освоены.
