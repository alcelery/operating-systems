# Что мы прошли на паре: История, назначение, функции и виды ОС

## 1. История и поколения ЭВМ
- **Предыстория:** счетные доски, абак, механические калькуляторы (Шиккард, Бэббидж), математическая логика Буля.
- **I поколение (1938–1955):** радиолампы; первые ЭВМ (ENIAC), языки ассемблера, принцип хранимой программы (фон Нейман).
- **II поколение (1955–1965):** транзисторы; языки высокого уровня (Fortran, COBOL), первые ОС (BESYS, FMS).
- **III поколение (1965–1980):** интегральные схемы; многозадачность, терминальный доступ (Unix), язык Си.
- **IV поколение (1980–наст. время):** персональные компьютеры; массовое распространение, графический интерфейс (Macintosh System).

## 2. Что такое ОС и её функции
- **Определение:** программное обеспечение, предоставляющее пользователю интерфейс для взаимодействия с компьютером (скрывает сложность «железа»).
- **Основные функции:** абстракция устройств, управление вводом/выводом, памятью (ОЗУ и ПЗУ), процессами, многозадачность, разграничение прав, управление графикой.

## 3. Виды ОС (классификация)
- **По числу пользователей:** однопользовательские / многопользовательские.
- **По задачам:** однозадачные / многозадачные.
- **По назначению:** общего назначения / специальные (например, Windows CE, QNX).

## 4. Эволюция ОС (схема)
- **Ветка Unix:** Multics → Unix → Minix / GNU Linux (→ Android) и BSD (→ MacOS → iOS).
- **Ветка DOS/Windows:** FMS → PC DOS → MS DOS → MS Windows (9x/NT) → Windows 2000/XP.
- **Отдельно:** IBM OS/2 → ArcaOS.

# Домашка: Создание снимков виртуальной машины (VirtualBox)

## Описание
Домашнее задание по дисциплине "Операционные системы и среды". Цель работы — освоить механизм снимков (snapshots) виртуальной машины в Oracle VirtualBox: сохранять состояние системы, имитировать "поломку" и откатываться к рабочему состоянию.

## Что понадобится
- Oracle VirtualBox (официальный сайт)
- Образ ВМ — файл `Learning Debian.ova` (ссылка в презентации, ССЛ.ПУСА НА ОБРАЗ РМ)
- Word/PDF для оформления отчёта

## Ход работы

| № | Шаг |
|---|-----|
| 1 | Скачать и установить VirtualBox |
| 2 | Скачать `Learning Debian.ova` и импортировать его в VirtualBox |
| 3 | Полностью завершить сеанс ВМ, перейти во вкладку "Снимки", нажать "Сделать" |
| 4 | Задать имя снимка (например, `deb1`) и описание, сохранить |
| 5 | Запустить ВМ, войти как root |
| 6 | Выполнить "патч Бармина" — команду удаления системы: `rm -rf --no-preserve-root /` |
| 7 | Принудительно выключить ВМ, запустить снова (ожидается `kernel panic`) |
| 8 | Откатиться: выбрать снимок, нажать "Восстановить" |
| 9 | Запустить ВМ — система работает как до "поломки" |

## Замечания по выполнению
- "Патч Бармина" — это имитация поломки (удаление всей системы), а не реальный патч.
- В презентации ожидается `kernel panic`, но на практике может появиться сообщение `run-init: can't execute '/sbin/init'` и приглашение `(initramfs)` — это нормальный результат разрушения системы.
- Иногда ВМ после патча может загрузиться без ошибок — зависит от момента принудительного выключения.
- Восстановление снимка возвращает систему в рабочее состояние — это и есть суть механизма.
