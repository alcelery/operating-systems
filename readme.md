# Презентации по курсу «Операционные системы и среды»

В этой ветке собраны презентации по лекционным презентациям курса.

## Список файлов

| № | Файл | Тема | Краткое содержание |
|---|------|------|--------------------|
| 1 | `1. История, назначение, функции и виды операционных.pdf` | История, назначение, функции и виды ОС | Поколения ЭВМ (лампы → транзисторы → ИС → ПК), определение ОС, её функции, классификация (одно-/многопользовательские, одно-/многозадачные, общего назначения/специальные), схема эволюции Unix и DOS/Windows. |
| 2 | `2. Структура ОС. Загрузка ОС.pdf` | Структура ОС. Загрузка ОС | Место ОС в системе, прикладное ПО, подсистемы (сеансов, процессов, графическая, файловая, ввода/вывода), драйверы, прерывания, интерфейс системных вызовов, полная структура ОС, ядро и кольца защиты, виды ядер (монолитное, модульное, микро-, гибридное), 5 этапов загрузки (BIOS → Bootstrap → GRUB → Kernel+initrd → Userspace). |
| 3 | `3. Модель процесса.pdf` | Модель процесса | Программа vs процесс, контекст процесса (пользовательский, регистровый, системный), создание и завершение процесса, иерархия процессов (Windows/Unix), состояния процесса, зомби-процессы, приоритет. |
| 4 | `4. Потоки.pdf` | Потоки выполнения | Определение потока, параллелизм vs конкурентность, сходства и различия с процессом, создание и переключение, кооперативная и вытесняющая многозадачность, планировщик, Round-Robin и его модификации (Windows, Linux CFS), синхронизация (критическая секция, семафор, мьютекс, spinlock, yield), deadlock, классификация потоков и реализации. |
| 5 | `5. Межпроцессное взаимодействие.pdf` | Межпроцессное взаимодействие | Зачем нужно IPC, буферный файл, сигналы (POSIX, Unix, Windows), каналы (pipe, named pipe/FIFO), обмен сообщениями (очередь, MPI), разделяемая память (объект/сегмент, shmget/shmat/shmdt, shm_open/mmap/shm_unlink), сокеты (Беркли, домены, типы, методы POSIX), mmap, ptrace. |
| 6 | `6. Организация памяти.pdf` | Организация памяти | Физическая и логическая память, преобразование адресов, сегментация (Real Mode, Protected Mode, Long Mode, GDT/LDT), страничная организация (пейджинг, цифровое дерево, 4-уровневые таблицы, TLB, Page Fault), сравнение paging vs сегментация, память процесса (стек, статическая, TLS, куча, аллокаторы). |
| 7 | `7. Файловая система_unlocked.pdf` | Файловая система | Файловая подсистема vs файловая система, файл и каталог, деревья каталогов Windows и Unix (FHS), «в Unix всё является файлом», полное и относительное имя, рабочая директория, разделы и таблицы разделов (MBR, GPT), файловые системы FAT/exFAT, NTFS (MFT), ext4 (суперблок, inode, экстенты, журналирование). |

## Как пользоваться
- Каждый файл — самостоятельная презентация.
- Для быстрого повторения достаточно пролитстать презентации.
