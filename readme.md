# Администрирование

## Описание
Домашнее задание по дисциплине "Операционные системы и среды". Цель работы — отработать практику взаимодействия с процессами (`ps`, `grep`, `head`) и справочной системой `man`. Все задания выполняются на виртуальной машине (Debian) в терминале.

## Что понадобится
- Oracle VirtualBox с импортированным образом ВМ.
- Терминал ВМ.
- Word/PDF для оформления отчёта.

## Ход работы

| № | Задание | Команда / ответ |
|---|---------|-----------------|
| 1 | Отобразить процессы в виде дерева. Какие аргументы использовать? | `ps -e --forest` (или `ps -ef --forest`); `-e` — все процессы, `--forest` / `f` — вид дерева |
| 2 | Найти все процессы, запущенные не от root | `ps -u root -N` |
| 3 | Вывести пять процессов, потребляющих больше всего памяти | `ps -eo pid,user,rss,cmd --sort -rss \| head -n 6` |
| 4 | Вывести все процессы, запущенные в фоновом режиме | `ps -eo pid,user,tty,cmd \| grep "?"` (у фоновых процессов нет TTY) |
| 5 | В `man cp` найти аргумент для сохранения владельца, прав и меток времени | `man cp`; аргумент `-a` (`--archive`), то же что `-dR --preserve=all` |
| 6 | В `man man` найти аргумент поиска по ключевым словам | `man man`; аргумент `-k` (поиск по ключевым словам) |
| 7 | Найти команду, делающую то же, что в п.6, и найти страницы по слову "copy" | Команда `apropos` (эквивалент `man -k`): `man -k copy` или `apropos copy` |

## Замечания по выполнению
- В задании 1 `ps -e --forest` показывает все процессы в виде дерева; без `-e` видны только процессы текущего терминала.
- `-N` у `ps` инвертирует выбор: `ps -u root -N` = все процессы, кроме принадлежащих root.
- Для сортировки по памяти: `--sort -rss` (знак минус — по убыванию), `rss` — резидентная память.
- Команда `head -n 6` в задании 3 использована потому, что первая строка — заголовок таблицы, а пять нужных процессов идут после неё.
- Фоновые процессы определяются по отсутствию терминала: в столбце TTY стоит `?`.
- `apropos` — отдельная утилита, являющаяся синонимом `man -k`; результат поиска по `copy` включает `cp`, `scpio`, `install`, `scp` и др.

## Требования к отчёту
- Оформляется в Word/PDF.
- Каждый шаг фиксируется: команда + скриншот вывода.
- В конце — вывод: какие знания извлечены, какие приёмы администрирования освоены.
